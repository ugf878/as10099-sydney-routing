## AS10099 是什么？和 AS9929、AS4837 什么关系

AS10099 是联通的海外业务承载网，2000 年 7 月在 APNIC 注册，旗下 IPv4 地址约 74% 分布在香港。按联通美洲官网对 Global DIA 产品的描述，这个网络在境外为客户提供专属 IP 和专线接入，并直连联通的国内骨干网。

AS9929 则是联通精品网（CUII），负责内地段的承载。很多文章把搬瓦工悉尼机房简称为“9929 线路”，但完整链路其实是两段拼接：流量出澳洲后先走 AS10099 到香港，再从 AS9929 进入广州、上海、北京的联通骨干。AS4837 是另一个东西，它是联通 169 普通骨干，定位和拥塞水平都跟前两者不同。ipinfo 的 ASN 数据里，AS10099 与 AS4837、AS9929 互为上下游，恰好印证了这种“海外段—内地段”的分工关系。

一句话概括：AS10099 管境外段，AS9929 管内地段，两者凑齐才算一条完整的精品链路。
